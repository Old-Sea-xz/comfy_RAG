# 发布整理与兼容范围

本包默认使用 `agentic_feedback`：恢复初始候选不足时的追加检索，并增加中途生成/修复的按需本地检索入口。发布整理主要处理部署入口和隐私边界：

- 提供 `tools/prepare_run.py`，从本地任务 JSON 准备独立批次；无需引用历史实验目录。
- ComfyUI、ComfyBench、媒体解释器和可选搜索 CLI 的机器路径改为环境配置或通用默认值。
- 子进程继承用户明确设置的代理；本地 ComfyUI 请求保持直连。
- 用当前 Python 解释器启动 worker，不要求某台服务器的虚拟环境路径。
- 提供统一运行/简洁进度命令，保留文件锁、队列、检查点和按失败类型统计的逻辑。
- 仅保留旧比较脚本中当前运行器实际依赖的公共函数，移除历史结果复制和旧外层重跑入口。
- 将可选几何适配使用的小型图补丁辅助函数放入包内，不依赖私人 Skill 安装目录。
- 发布工作流移除 UI/provenance 元数据，并使用通用媒体占位符；保留执行所需的 handoff 等注解。发布图的哈希已重算。
- 匿名描述与其检索向量保持对应，保留向量哈希、ID 顺序与逐描述哈希检查。
- 保留单次检索兼容分支的离线测试，并新增反馈检索次数、停止条件、修复检索决策与恢复的测试。
- 默认原生队列依赖的服务端清理/恢复逻辑单独发布在 `integrations/comfyui/`；安装器校验固定上游版本，不改动已有环境。离线测试读取随包 worker 和 helper，不依赖相邻的私人 ComfyUI checkout。

没有发布真实 API 配置、模型权重、自定义节点代码、benchmark 媒体、历史分类结果或生成/评价产物。工作流中的模型文件名和节点类型是接口依赖，不是已安装或可执行的保证。

ComfyBench 的官方评测代码由外部 checkout 提供；用户应使用与自身实验相匹配的版本和评测输入。66 份图所依赖的第三方模型、自定义节点和其各自授权由对应上游项目提供。本仓库没有复制这些权重或节点仓库。

按 RAG 单独发布范围，已移除分类树遍历/构建、JEV、独立拆分、模型分类、增量 Skill 库和跨任务自进化。生成、评价、修复、媒体接口与文件锁继续复用现有执行逻辑。`decomposition_step` 等历史字段只是联合选择所返回的执行阶段元数据，不会触发单独拆分请求。
