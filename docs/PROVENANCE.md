# 来源与本次整理

基础文件来自工作区 `comfy_RAG` 独立发布副本：执行器、匿名工作流库、E5 向量、部署入口、脱敏配置与离线测试。

初始反馈检索分支对照 `run_logs/rag_capability_top20_comfybench200_20261022/source_snapshot/tools/run_anonymous_md_comparison.py` 中非 `capability_single_pass` 分支恢复：原始请求首次检索、Agent 输出 `search_needed/search_query`、最多三轮、仅使用当前候选窗口、无分类树。原实验目录的 README 存在“累积候选”文字与该源码不一致的情况，本包以这份源码的当前窗口行为为准。

本次新增 `comfyrouter/agentic_retrieval.py` 及统一规划入口 hook，让初始准备、预检错误、执行失败和质量修复可按需追加本地工作流检索。它向当前修复提供参考图和描述，不自动替换整条工作流链。原执行器中根据 Agent 判断搜索外部资料的机制继续保留。

本包保留完整的最多三次 GPU 执行预算；旧反馈检索快照中“额外初始检索占用执行轮次”的预算规则未沿用，以支持本次要求的迭代中按需检索。检索不会重置执行或修复轮次。

这是一份按本次要求整理并扩展的可运行代码包，不是历史实验结果的原样复现包。未重新进行 GPU 生成实验。分类树构建/遍历、JEV、分类器和跨任务自进化实现均未收入。
